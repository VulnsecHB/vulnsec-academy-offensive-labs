CONFIRM IT IS BLIND

The page only answers yes or no.

A real reference returns Invoice on file. A fake one returns No matching invoice. Amounts never appear. SQL errors are swallowed, so a quote looks like a miss. That is boolean-blind injection — sqlmap will infer data from the two page shapes.

INV-44190Known-good reference (true page)

REMEDIATION

Blind is still injection.

Hiding error text and query results does not fix concatenation. Bind parameters. A yes/no page is enough for sqlmap to empty the database.
