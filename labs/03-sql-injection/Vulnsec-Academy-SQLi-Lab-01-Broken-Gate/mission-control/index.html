AUTHENTICATION SQLi

Break the login query.

Northline Staff Access concatenates the username into a SQL statement. A tautology in that field, plus a comment, skips the password check and returns the first matching row — the administrator.

' OR 1=1--Makes the WHERE clause always true
--Comments out the password predicate
usernameThe unsafe, concatenated parameter
WHY THIS WORKSThe application builds SQL with string formatting instead of a parameterized query. The database therefore executes attacker-controlled logic.

REMEDIATION

Never concatenate SQL.

Use parameterized queries, hash passwords, and grant the application account only the statements it needs. A tautology in a login form should never become a session.
