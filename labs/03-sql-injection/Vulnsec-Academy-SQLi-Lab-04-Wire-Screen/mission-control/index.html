02

SEE THE SCREEN

Spaced keywords never reach SQL.

A clean pass returns a holder card. A classic UNION SELECT or ' AND 1=1 returns HTTP 403 from the perimeter screen. The filter looks for whitespace around SQL words — not for /**/ comments.

passUnsafe GET parameter
YA-10442Known-good pass identifier
403Signature hit — payload never executed
03

SQLMAP TAMPER

Replace spaces with comments.

space2comment turns UNION SELECT into UNION/**/SELECT. The screen no longer sees a spaced keyword, and the backend still treats the comment as whitespace.

--tamper=space2commentBypasses the space filter
--batchAccepts default answers
-T users --dumpExtracts the credential rows

REMEDIATION

Filters are not queries.
