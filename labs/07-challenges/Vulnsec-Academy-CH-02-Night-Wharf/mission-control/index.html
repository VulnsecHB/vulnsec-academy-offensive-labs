04

ENUMERATE THE SHELL

Do not assume which cage you are in.

SSH only gives a prompt. Identify the shell, list what you can run, and record what fails. A private PATH, a refused cd, and a refused command that contains a slash is the signature of restricted bash (rbash) — not a broken install.

echo $0 $SHELLNames the login shell
echo $PATH && ls binEvery binary you are allowed
cd /Refused — confirms the cage
05

GTFOBINS ESCAPE

Look up every allowed binary.

Open gtfobins.github.io and search the allow-list one name at a time. ls, cat, echo, pwd, date and whoami have no shell escape that helps inside rbash. awk does — it can call system() and start a real bash. After that, this shell still inherited the tiny PATH, so reset it before you try sudo.

awkGTFOBins → Shell
system("/bin/bash")Leaves rbash
export PATH=...Unhides sudo, find, id
06

PRIVILEGE ESCALATION

Enumerate sudo the same way.

Do not hunt random SUID binaries first. Ask sudo what this account may run. sudo -l returns a single NOPASSWD path: /usr/bin/find. GTFOBins → find → Sudo is a root shell. Then read /root/root.txt.

sudo -lDo not skip this — it names the binary
gtfobins / findSudo function is a root shell
/root/root.txtSecond flag
