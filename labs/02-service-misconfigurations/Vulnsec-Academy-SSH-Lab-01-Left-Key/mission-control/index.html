01

LAND + LOOK

Password gets you on. The key is next door.

SSH as s.crane. Read the note in home, then list other homes. /home/n.quay/.ssh is traversable and id_rsa is 644 — world-readable. That is the misconfig. OpenSSH on Kali will refuse to use a 644 key, so copy it off and lock the mode.

644 id_rsaAnyone on the box can read it

02

LIFT + LOGIN

Use the key from Kali, not from a world-readable path.

Copy the file to your attacking host, drop the mode, then ssh -i as n.quay. Password auth is locked for that account. The flag is in that user’s home.

scpPull id_rsa to Kali
ssh -iLogin as n.quay
