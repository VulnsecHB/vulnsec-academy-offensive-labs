12 TOOLS
01 · RECONnmap

Nmap

Network mapper. You give it an address; it tells you which TCP (and UDP) ports are open and what is listening. You scan before you browse. Default nmap is the top 1000 ports, not every port. -sV fills the version column. -p- is every TCP port — cheap on one authorised host, not on a range.

-sVService and version detection
-PnSkip ping; treat the host as up
-p-All 65535 TCP ports
-p80One port only — a test, not a sweep

USED IN First Sweep · Odd Berth

02 · RECONcurl

curl

Fetch a URL from the terminal. Faster than a browser when you only need the body, a header, or a grep. wget does the same job for downloads. If the service is not on port 80, the URL must include the port.

-sSilent — no progress meter
-IHeaders only
-o fileWrite to a file (tool transfer)
:8088Required when HTTP is not on 80

USED IN every web lab · Loud Enumerator (pull tools)

03 · WEB FUZZgobuster dir

Gobuster

Directory and file brute-force. The public nav is not the site. You point gobuster at a URL and a wordlist; it reports status codes. 200 is live. 404 is noise. 301/302 is a redirect worth following. robots.txt is a hint file, not an inventory — Disallow does not mean the path exists.

dirDirectory/file mode
-uBase URL
-wWordlist (dirb/common.txt is enough here)
-xExtensions: bak,old,txt — files, not folders

USED IN Unlisted Door · Nested Hold

04 · WEB FUZZffuf

ffuf

Same job as gobuster, different syntax. FUZZ is the placeholder the wordlist fills. -e is gobuster’s -x. Use whichever you have; Atlas accepts both in the fuzz labs.

-u .../FUZZInjection point
-wWordlist
-e .bak,.old,.txtExtensions

USED IN Unlisted Door · Nested Hold (equivalent)

05 · ACCESSssh

SSH

Remote shell. In the privesc module the briefing gives you the account. That is not a skip — you still take user.txt before you escalate. Password auth in these labs. Do not confuse the SSH banner with a vulnerability.

user@hostIssued operator
user.txtAlways grab this first
sudo -lFirst command inside, even if it fails

USED IN Borrowed Bin · Clockwork · Setuid Tide · Loud Enumerator

06 · PRIVESCsudo -l

sudo -l

Ask what this account may run as root. Do this before you guess binaries or kernels. NOPASSWD means you do not need the user’s password for that command. An empty result is also a finding — then you look at cron and SUID.

sudo -lList allowed commands
NOPASSWDNo password for that path
(root)Runs as root, not as you

USED IN Borrowed Bin (hit) · later labs (empty on purpose)

07 · PRIVESCgtfobins.github.io

GTFOBins

A catalogue of Unix binaries that can be abused when you can run them in a privileged context. You look up the program, not the filename. Two columns you will use: Sudo (you may run it via sudo) and SUID (the setuid bit is on). They are not interchangeable. less as sudo uses ! inside the pager. env as SUID runs /bin/sh -p.

SudoBorrowed Bin — less + !/bin/sh
SUIDSetuid Tide — env /bin/sh -p
-pKeep euid 0; a login shell may drop it
filenameMay be a lie. --help / file first

USED IN Borrowed Bin · Setuid Tide

08 · PRIVESCfind -perm -4000

find (SUID)

List files that keep the setuid bit. Stock helpers (passwd, sudo, newgrp, mount) are expected. A custom name under /usr/local is not. Identify what that file actually is before you open GTFOBins.

-perm -4000Setuid bit is on
-type fFiles only
2>/dev/nullHide permission denied noise
--helpFilename is not the program

USED IN Setuid Tide

09 · PRIVESC/etc/cron.d

Cron

Root’s clock. If sudo is empty, read scheduled jobs. A script executed as root that you can write is the job. Overwrite it, wait for the minute, take a SUID bash. Reverse shells need a path back to Kali — on an internal Docker net they often die. SUID bash does not need the network. /tmp/rootbash -p keeps root.

/etc/cron.dSystem jobs, often root
ls -l scriptLook for 777 / world-writable
sleep 60The clock is one minute
-pSUID bash must not drop euid

USED IN Clockwork

10 · TRANSFERpython3 -m http.server

Move tools onto the box

linPEAS is not installed on the target. You fetch it on Kali, serve the folder, and curl it from the target. Bind 0.0.0.0 or the container cannot reach you. Confirm the gateway with ip route — often 10.23.54.1, not always. scp file user@host:/tmp/ is the backup if HTTP the other way fails. wget is curl’s twin.

http.serverKali, all interfaces
ip routeDefault via = gateway
curl -oWrite the script in /tmp
scpSame direction as SSH

USED IN Loud Enumerator

11 · ENUMlinpeas.sh

linPEAS

Automated Linux privilege-escalation enumerator (PEASS-ng). It is loud on purpose. Yellow/red is interesting; the whole scroll is not a to-do list. In Loud Enumerator the Capabilities block is the path. Kernel CVEs, linux-exploit-suggester, and a MOTD that claims kernel 4.4.0 are decoys — the container kernel is the host kernel. Do not run Dirty COW or any kernel PoC in these labs.

linPEASPrimary tool in lab 8
linuxprivchecker.pyOlder optional alternative, same transfer
kernelNoise here. Never the intended path
colourRead it. Do not fire every CVE

USED IN Loud Enumerator — last lab, after you can read sudo/cron/SUID by hand

12 · PRIVESCgetcap

getcap

Linux file capabilities. Narrower than full root, still enough. cap_setuid+ep on Python means the process can call os.setuid(0) and then spawn a root shell. linPEAS prints this; you can also ask without linPEAS. Same family of idea as SUID, different bit.

getcap -r /Walk the filesystem
cap_setuidBecome uid 0 from userspace
os.setuid(0)Python one-liner, then execl sh -p

USED IN Loud Enumerator
